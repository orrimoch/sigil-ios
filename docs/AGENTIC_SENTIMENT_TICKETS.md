## Problem Statement

Current keyword-based sentiment scoring produces 62% neutral scores (420/677 stocks). This low signal-to-noise ratio undermines the sentiment component's contribution to composite scoring.

## Solution

Upgrade to LLM-powered sentiment analysis using Claude API. The agentic approach understands financial context, nuance, and complex market narratives that keyword matching misses.
