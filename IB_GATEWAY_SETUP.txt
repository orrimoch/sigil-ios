STEP 1: Mount the HFS+ Volume
================================================================================

  The Mac mini uses case-sensitive APFS, which breaks IB Gateway's Java code.
  IB Gateway lives on a case-insensitive HFS+ sparse image instead.

  hdiutil attach /tmp/ibgateway_volume.sparseimage

  This mounts to: /Volumes/IBGateway
  IB Gateway is at: /Volumes/IBGateway/IB Gateway 10.37/

  If the sparse image is missing (e.g. after reboot of /tmp):
    hdiutil create -size 2g -fs HFS+ -volname IBGateway /tmp/ibgateway_volume.sparseimage
    hdiutil attach /tmp/ibgateway_volume.sparseimage
    # Then copy IB Gateway back:
    cp -R ~/Applications/IB\ Gateway\ 10.37/ /Volumes/IBGateway/IB\ Gateway\ 10.37/

================================================================================
STEP 2: Start IB Gateway via IBC (automated login)
================================================================================

  cd ~/ibc && bash gatewaystartmacos.sh -inline

  IBC handles:
    - Launching IB Gateway from /Volumes/IBGateway
    - Auto-entering username + password
    - Selecting paper trading mode
    - Accepting API connections
    - Dismissing popups/dialogs

  Config file: ~/ibc/config.ini
  Logs: ~/ibc/logs/

  Wait ~30 seconds for Gateway to fully initialize and show "DUP526287".

================================================================================
STEP 3: Verify Gateway is Running
================================================================================

  Check the port is open:
    lsof -i :4002

  Should show a Java process listening on port 4002 (pxc-spvr-ft).

  Quick Python test:
    python3 -c "
    from ib_insync import IB
    ib = IB()
    ib.connect('127.0.0.1', 4002, clientId=99)
    print('Connected:', ib.isConnected())
    print('Account:', ib.managedAccounts())
    ib.disconnect()

================================================================================
TROUBLESHOOTING
================================================================================

  PROBLEM: "Volume not mounted"
    FIX: hdiutil attach /tmp/ibgateway_volume.sparseimage

  PROBLEM: "Address already in use" on port 4002
    FIX: An old Gateway is still running. Kill it:
         pkill -f "ibgateway" or kill the Java PID from: lsof -i :4002

  PROBLEM: IBC fails to log in / hangs
    FIX: Check ~/ibc/config.ini has correct credentials.
         Check ~/ibc/logs/ for error details.
         Try restarting: pkill -f java && cd ~/ibc && bash gatewaystartmacos.sh -inline

  PROBLEM: "Gateway auto-exits" after API client disconnects
    FIX: This is normal IB Gateway behavior. Restart with:
         cd ~/ibc && bash gatewaystartmacos.sh -inline

  PROBLEM: Sparse image missing after reboot
    FIX: /tmp is cleared on reboot. Recreate per Step 1 instructions.
         Consider moving the sparse image to ~/ibgateway_volume.sparseimage
         to survive reboots.

  PROBLEM: Backend can't connect to Gateway
    FIX: 1) Verify Gateway is running: lsof -i :4002
         2) Verify backend is running: curl http://127.0.0.1:8000/
         3) Try reconnect: curl -X POST http://127.0.0.1:8000/api/v1/ibkr/connect

API COMMANDS — Trading
================================================================================

  # Basic market order
  curl -X POST http://127.0.0.1:8000/api/v1/ibkr/order \
    -H "Content-Type: application/json" \
    -d '{"ticker": "AAPL", "side": "BUY", "quantity": 10, "order_type": "MARKET"}'

  # Limit order
  curl -X POST http://127.0.0.1:8000/api/v1/ibkr/order \
    -H "Content-Type: application/json" \
    -d '{"ticker": "AAPL", "side": "BUY", "quantity": 10, "order_type": "LIMIT", "limit_price": 175.00}'

  # Stop order
  curl -X POST http://127.0.0.1:8000/api/v1/ibkr/order \
    -H "Content-Type: application/json" \
    -d '{"ticker": "AAPL", "side": "SELL", "quantity": 10, "order_type": "STP", "limit_price": 170.00}'

  # Stop-limit order
  curl -X POST http://127.0.0.1:8000/api/v1/ibkr/order \
    -H "Content-Type: application/json" \
    -d '{"ticker": "AAPL", "side": "SELL", "quantity": 10, "order_type": "STP_LMT", "limit_price": 169.00, "stop_price": 170.00}'

  # Trailing stop (percent-based) — NEW
  curl -X POST http://127.0.0.1:8000/api/v1/ibkr/order \
    -H "Content-Type: application/json" \
    -d '{"ticker": "AAPL", "side": "SELL", "quantity": 10, "order_type": "TRAIL", "trailing_percent": 5.0}'

  # Trailing stop (fixed amount) — NEW
  curl -X POST http://127.0.0.1:8000/api/v1/ibkr/order \
    -H "Content-Type: application/json" \
    -d '{"ticker": "AAPL", "side": "SELL", "quantity": 10, "order_type": "TRAIL", "trailing_amount": 10.00}'

  # Extended hours order (pre-market/after-hours) — NEW
  curl -X POST http://127.0.0.1:8000/api/v1/ibkr/order \
    -H "Content-Type: application/json" \
    -d '{"ticker": "AAPL", "side": "BUY", "quantity": 10, "order_type": "LIMIT", "limit_price": 175.00, "outside_rth": true}'

  # Good-Till-Date order — NEW

    -H "Content-Type: application/json" \
    -d '{"ticker": "AAPL", "side": "BUY", "quantity": 10, "order_type": "LIMIT", "limit_price": 175.00, "tif": "GTD", "good_till_date": "20260210 16:00:00"}'

  # Time-in-force options: DAY (default), GTC, GTD, IOC, FOK
