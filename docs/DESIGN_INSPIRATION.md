# Design Inspiration — TradingApp iOS

**Style:** Institutional Dark — Bloomberg/IBKR aesthetic  
**Target User:** The Busy Builder (tech professional, 30-40, sophisticated)  
**Philosophy:** Professional trust over flashy fintech

---

## 🎯 Design Direction

**"Institutional Trust for the Busy Builder"**

The app should feel like a Bloomberg terminal distilled for mobile — sophisticated enough to earn respect, efficient enough to use in 30 seconds between meetings. No learning curve, no clutter, no wasted taps.

> ❌ NOT: Robinhood (gamified), Headspace (wellness), Neon fintech startups
> ✅ YES: Bloomberg, Interactive Brokers, Fidelity, Charles Schwab

## 🎨 Color Palette — "Institutional Dark"

```
BACKGROUNDS
───────────────────────────────
Background:      #000000    True black
Surface:         #0D0D0D    Cards, elevated
Surface 2:       #161616    Modals, inputs
Border:          #222222    Dividers
Border Active:   #333333    Focus states

SEMANTIC (Industry Standard)
───────────────────────────────
Gain/Positive:   #00C853    Green (price up, buy)
Loss/Negative:   #FF1744    Red (price down, sell)
Neutral:         #9E9E9E    Gray (hold, unchanged)
Primary Action:  #2196F3    Blue (buttons, CTAs)
Warning:         #FFC107    Amber (alerts)
Info:            #03A9F4    Light blue

TEXT
───────────────────────────────
Text Primary:    #FFFFFF    Headlines, prices
Text Secondary:  #B0B0B0    Labels
Text Muted:      #707070    Timestamps, hints
Text Disabled:   #404040    Disabled states
```

## 📐 Typography

| Purpose | Font | Fallback |
|---------|------|----------|
| UI Text | SF Pro Text | -apple-system |
| Numbers/Data | SF Mono | Menlo, Monaco |
| Headlines | SF Pro Display | -apple-system |

**Key Rules:**
- All financial numbers in SF Mono (monospace)
- Right-align all numeric data
- Proper number formatting: `$1,234.56`, `+2.34%`

## ✅ Design Checklist

- [x] True black (#000000) background
- [x] Standard trading colors (green gain, red loss)
- [x] SF Mono for all financial numbers
- [x] Right-aligned numeric columns
- [x] Bloomberg-style data tables
- [x] Minimal decorative elements
- [x] High information density
- [x] Instant readability (no hunting for data)

---

## 📝 What We're NOT Doing

| Avoid | Why |
|-------|-----|
| Gamified UI (confetti, celebrations) | Undermines trust |
| Vibrant neon colors | Looks like crypto scam |
| Rounded, playful typography | Not professional |
| Excessive animations | Wastes user's time |
| Wellness/meditation aesthetic | Wrong audience |
| Startup-y gradients | Lacks institutional gravitas |
